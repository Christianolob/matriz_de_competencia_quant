# Quant BR

Dois projetos independentes, cada um com seu `run.bat`:

| Pasta | O que é | Como abrir |
| --- | --- | --- |
| [`matriz_competencias/`](matriz_competencias/README.md) | Matriz de competências quant (skill tree circular com editor) | `matriz_competencias\run.bat` → http://localhost:8000/ |
| [`empresas_quant/`](empresas_quant/README.md) | Lista de empresas brasileiras com trabalho quantitativo (bancos, hedge funds, pagamentos…) coletada do BCB e da CVM | `empresas_quant\run.bat` → http://localhost:8010/ |

Ambos usam só Python (stdlib), sem dependências para instalar.
